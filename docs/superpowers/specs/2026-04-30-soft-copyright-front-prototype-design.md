# 软著生成工具前端原型设计

日期：2026-04-30

## 目标

首版交付一个可演示的 Vue 单页前端原型，用于展示“输入系统标题后生成软著材料”的完整产品路径。原型重点覆盖首页工作台、设置界面、历史记录、执行过程、资源预览/编辑、模板解析配置和生成结果展示。

首版不接真实 Agent、不做真实 docx 生成、不做真实本地文件写入。所有执行过程、产物内容、路径、统计信息和 Agent 响应先使用高质量模拟数据，保证演示流程完整。

## 范围

### 包含

- 首页系统标题输入、系统类型选择、开始生成。
- 开始生成前的必要信息校验。
- 四阶段执行过程：项目分析、项目编码、图片截取、文档生成。
- 大节点和小节点状态展示、重新生成、建议后重新生成。
- 资源产物查看、编辑或预览。
- 生成结果摘要：项目地址、文档地址、压缩包、统计信息。
- 历史记录列表、删除、加载历史执行信息。
- 设置页：基本信息、模板配置、Agent 配置、备注信息、系统设置。
- 模板上传、Agent 模拟解析、解析结果查看和编辑、解析 JSON 导入导出。
- 本地状态和 localStorage 持久化。

### 不包含

- 真实 Agent API 调用。
- 真实 docx 读取、解析和写入。
- 真实截图、真实 zip 压缩、真实文件目录打开。
- Tauri 桌面壳和系统级文件权限。
- HTML 演示界面的代码编辑。

## 信息架构

应用使用单页结构，顶部或侧边提供三个主入口：

- 首页
- 设置
- 历史记录

首页是主工作台。设置页负责准备生成依赖。历史记录负责回放已生成任务。

## 首页工作台

首页采用“紧凑输入和结果摘要 + 大面积执行流程”的布局。

### 输入区

- 系统标题输入。
- 系统类型选择，首版默认支持 Web 端。
- 开始生成按钮。

点击开始生成后，系统先执行校验，不直接启动生成。

### 生成前校验

校验规则：

- 项目标题必须填写。
- 产出资源目录必须设置。
- 至少存在一个已解析完成的模板。
- Agent 配置必须可用，包括 baseUrl、apiKey、model，并且测试状态为可用。

校验失败时：

- 不启动执行流程。
- 首页流程区显示待配置项清单。
- 每个待配置项提供跳转到设置页对应区域的入口。
- 标题为空时在输入框附近显示明确提示。

校验通过后，进入模拟生成流程。

## 执行流程

执行流程按四个阶段顺序推进：

### 1. 项目分析

固定生成三个资源：

- 《项目功能设计文档》
- 《项目架构设计及技术选型文档》
- 《项目页面流程设计文档》

每个资源支持查看/编辑、重新生成、建议后重新生成。

### 2. 项目编码

生成用于演示项目功能的 HTML 高保真界面。该界面只要求能演示主要功能，数据尽可能真实。

资源操作：

- 预览。
- 重新生成。
- 建议后重新生成。

HTML 演示界面不提供代码编辑功能。

### 3. 图片截取

生成三个资源组：

- 根据架构设计文档生成线框型项目架构图。
- 根据页面流程设计文档生成线框型软件功能流程图。
- 截取各功能界面截图并形成截图集。

图片和截图类资源支持预览、重新生成、建议后重新生成。图片说明文本可以编辑，但不直接编辑图片本体。

### 4. 文档生成

文档生成节点根据设置页中的模板配置动态生成。配置了哪些模板，就生成哪些文档。

例如：

- 只配置说明书模板时，只生成软件说明书。
- 配置采集表、说明书、源代码模板时，生成对应三类文档。

每个模板生成文档支持查看/编辑、单独重新生成、建议后重新生成。

## 节点状态和资源模型

节点状态包括：

- 待开始
- 生成中
- 已完成
- 需处理
- 失败

每个小节点包含：

- 节点名称。
- 所属阶段。
- 状态。
- 资源类型。
- 资源内容或预览信息。
- 生成时间。
- 重新生成次数。
- 建议重生成记录。

## 资源交互

资源交互使用统一弹窗，但按资源类型展示不同内容。

### 文档类资源

适用于项目分析文档和最终模板文档。

弹窗内容：

- 资源标题。
- 正文编辑区。
- 关联来源说明。
- 保存。
- 重新生成。
- 建议后重新生成。

### HTML 演示界面

弹窗内容：

- 预览入口。
- 页面清单。
- 生成说明。
- 重新生成。
- 建议后重新生成。

不提供 HTML 代码编辑。

### 图片和截图类资源

弹窗内容：

- 图片或截图占位预览。
- 图片说明文本。
- 重新生成或重新截取。
- 建议后重新生成。

## 执行结果

结果区展示：

- 项目地址：模拟本地预览地址，点击弹出预览提示。
- 文档地址：模拟文档输出目录，点击显示目录提示。
- 压缩包：初始置灰；文档生成完成后启用一键压缩；点击后生成模拟压缩包地址。
- 统计信息：生成耗时、资源数量、模板数量、重新生成次数、最近完成时间。

## 历史记录

历史记录保存到 localStorage。

列表字段：

- 系统标题。
- 系统类型。
- 执行状态。
- 生成时间。
- 模板数量。
- 资源数量。
- 耗时。

操作：

- 点击历史记录加载当时的输入、执行流程、产物和统计信息。
- 删除历史记录。

## 设置页

设置页采用分组配置结构：

- 基本信息设置。
- 模板配置。
- Agent 配置。
- 备注信息。
- 系统设置。

### 基本信息设置

字段包括：

- 产出资源目录。
- 著作权人。
- 详细地址。
- 邮政编码。
- 联系人。
- 电话号码。
- Email。
- 手机号码。
- 传真号码。
- 开户银行。
- 银行账号。
- 申请人名称。

公司基本信息在原型中作为可编辑配置保存，用于后续模拟文档生成。

### 模板配置

模板配置是首版重点。

用户上传普通 docx 模板文件，模板文件中不要求预先标注占位符。系统通过模拟 Agent 分析模板。

模板卡片字段：

- 模板名称。
- 文档类型。
- 原始文件名。
- 解析状态。
- 结构节点数量。
- 动态内容字段数量。
- 样式规则数量。
- 最后解析时间。

模板操作：

- 上传模板文件。
- 调用 Agent 解析模板。
- 查看/编辑解析结果。
- 导入解析 JSON。
- 导出解析 JSON。
- 删除模板。

不提供一键验证和一键修复。

### 模板解析模型

Agent 解析结果包含两类核心信息：模板结构和 Word 样式。

模板结构包括：

- 封面。
- 目录。
- 正文标题。
- 章节段落。
- 表格。
- 图片或截图位置。
- 签章区。
- 源码区。
- 附录区。

动态内容映射包括：

- 项目名称。
- 著作权人信息。
- 公司基本信息。
- 功能描述。
- 技术架构。
- 页面说明。
- 流程说明。
- 源码片段。
- 截图说明。
- 生成日期。

Word 样式信息包括：

- 字体。
- 字号。
- 字体颜色。
- 加粗、斜体、下划线。
- 段前间距。
- 段后间距。
- 行间距。
- 首行缩进。
- 左对齐、右对齐、居中、两端对齐。
- 标题层级。
- 编号规则。
- 表格行列结构。
- 表格边框。
- 单元格背景、宽度和对齐。

解析结果编辑器允许调整：

- 模板结构节点名称。
- 节点用途。
- 动态内容字段。
- 字段来源。
- 生成说明。
- 样式识别结果。
- 是否参与最终生成。

### Agent 配置

字段包括：

- baseUrl。
- apiKey。
- model。

操作包括：

- 保存配置。
- 测试连接。
- 导入配置 JSON。
- 导出配置 JSON。

测试连接在原型中使用模拟状态。首页生成前校验读取该状态。

### 备注信息

提供补充要求输入区。该信息会作为模拟生成的全局补充要求。

### 系统设置

字段包括：

- 主题。
- 版本信息。

首版可提供浅色、深色或跟随系统的选项，但实际视觉可以先以浅色为主。

## 数据持久化

首版使用 localStorage 保存：

- 全局设置。
- 模板解析结果。
- 当前任务。
- 历史记录。
- 资源编辑内容。

数据结构应保持接近后续真实实现，避免原型和真实版本完全割裂。

## 错误和空状态

需要覆盖以下状态：

- 未填写标题。
- 未设置产出资源目录。
- 未配置模板。
- 模板未解析完成。
- Agent 配置缺失。
- Agent 测试不可用。
- 生成中禁止重复启动。
- 资源重新生成失败。
- 历史记录为空。

错误提示应直接给出下一步操作入口。

## 验收标准

- 用户可以完成从填写标题到模拟生成全部资源的演示路径。
- 未完成必要配置时，开始生成会显示明确校验失败原因，包括标题、产出资源目录、模板和 Agent 配置。
- 文档生成节点严格跟随模板配置动态变化。
- HTML 演示界面只有预览和重新生成，没有代码编辑。
- 模板解析表现为 Agent 对普通 docx 的结构、动态内容和 Word 样式分析。
- 设置、模板、历史记录刷新后仍能保留。
- 历史记录可以加载回当时的执行信息。
